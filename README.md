# Fashion-Recommender-System

A content-based image recommendation system that suggests visually similar fashion items. Built using ResNet50 CNN for feature extraction and trained on 10,000 fashion images. Deployed as a Streamlit web app for interactive demos.

🚀 Features

Upload an image and get top visually similar product recommendations.

Works for various categories like shirts, pants, dresses, etc.

Built with TensorFlow, ResNet50, NumPy, and Streamlit.

Uses precomputed feature vectors for fast similarity search.

🧠 Model

ResNet50 CNN model used for feature extraction.

Trained on 10,000 fashion images to learn visual embeddings.

Cosine similarity is used to find the closest matches.
